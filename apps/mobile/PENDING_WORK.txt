Blunow Pending Work

Connection Slots
Status: Pending

Build Blunow around limited, intentional active connections instead of unlimited swiping.

- Limit each user to a small number of active connection slots, such as 3.
- Replace generic Connect / Like actions with Request Slot, Accept Slot, Close Slot, and Message.
- Show active slot usage in discovery and chat surfaces.
- Require a respectful closure reason before a user frees a slot.
- Add hidden Report / Safety Concern handling inside the closure flow so unsafe behavior can be routed to moderation without alerting the reported user.

Slot Abuse Protection
Status: Pending

Prevent users from recreating swipe-app behavior inside the slot system.

- Auto-close inactive slots after 48 hours of mutual silence.
- Auto-close inactive slots after 36 hours of one-sided silence.
- Send a reminder before an automatic inactivity closure.
- Apply a queue pause-lock when a user cycles through too many slots in 24 hours.
- Track slot open / close velocity on the user trust profile.

Intent Lock
Status: Pending

Make matching depend on relationship intent and reduce intent gaming.

- Add relationship intent selection, such as serious relationship, slow dating, marriage-minded, casual but respectful, and friendship first.
- Filter discovery queue by compatible intent.
- Track recent intent changes.
- Lower queue priority or slow queue population when intent changes too frequently.
- Show intent match as a primary discovery signal.

Personality-First Unlock
Status: Pending

Move discovery away from photo-first judgment while keeping enough visual trust for adoption.

- Use progressive reveal instead of fully hidden photos.
- Show intent, values, lifestyle rhythm, prompt, and compatibility before the full gallery.
- Keep one limited visual preview before slot acceptance.
- Unlock the primary photo after both users accept a slot.
- Unlock gallery photos after conversation milestones.
- Add UI states for locked gallery, partial unlock, and full unlock.

Frontend Pending Surface Area
Status: Pending

- app/(tabs)/matches.tsx: currently behaves like a swipe deck with like, chat, boost, and pass actions.
- components/discover/DiscoverUserCard.tsx: currently prioritizes avatar, match score, interests, and generic Connect.
- app/(screens)/match-detail/[profileId].tsx: currently shows full photo-first detail and standard like/chat actions.

- hooks/queries.ts: currently only has a matches query; slot queries and mutations are not defined.
- store/matchStore.ts and types/match.types.ts: currently do not define slot state or typed frontend models.
